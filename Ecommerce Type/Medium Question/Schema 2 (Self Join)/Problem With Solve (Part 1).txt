প্রশ্ন ১:
যে ছাত্ররা টানা ৩ দিন উপস্থিত ছিল (status = 'Present'), তাদের নাম বের করো।


Schema : 
CREATE TABLE Attendance (
    id INT PRIMARY KEY,
    student_name VARCHAR(50),
    attend_date DATE,
    status VARCHAR(10)
);


Solve : 
select distinct a1.student_name from attendance as a1
    join attendance as a2 on a1.id=a2.id-1
    join attendance as a3 on a1.id=a3.id-2
    where a1.status='Present' AND a2.status='Present' AND a3.status='Present';






প্রশ্ন 2:
একটা প্রোডাক্টের দাম যদি টানা ৩ দিনে কমে (price decreases), তাহলে সেই প্রোডাক্টের নাম বের করো।


Schema : 
CREATE TABLE ProductPrice (
    id INT PRIMARY KEY,
    product_name VARCHAR(50),
    price_date DATE,
    price DECIMAL(10,2)
);


Solve : 
 select distinct p1.product_name from ProductPrice as p1
   join ProductPrice as p2 on p1.id=p2.id-1
    join ProductPrice as p3 on p1.id=p3.id-2
   where p1.price > p2.price AND p2.price > p3.price;







প্রশ্ন 3:
যে ইউজাররা টানা ৩ বার ভুল পাসওয়ার্ড দিয়েছে (failed login) তাদের বের করো।


Schema : 
CREATE TABLE LoginAttempts (
    id INT PRIMARY KEY,
    username VARCHAR(50),
    attempt_time DATETIME,
    status VARCHAR(10) -- 'Success' or 'Failed'
);



Solve : 
select distinct l1.username from LoginAttempts as l1
    -> join LoginAttempts as l2 on l1.id=l2.id-1
    -> join LoginAttempts as l3 on l1.id=l3.id-2
    -> where l1.status=l2.status and l2.status=l3.status and l2.status='Failed';
